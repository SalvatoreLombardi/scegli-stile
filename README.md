# Scegli Stile

Strumento di presentazione per far scegliere ai clienti palette, font, bottoni e card.
Pensato per iPad Air 2 (1024×768 punti, Safari iPadOS 15). Nessun dato dei clienti, nessun server.

- `npm run dev` per lavorarci, `npm run build` per la versione finale.
- Colori, font e stili si modificano in `src/dati.js`.
- Pubblicazione: push su `main` e GitHub Actions (`.github/workflows/deploy.yml`) pubblica su GitHub Pages
  (Settings → Pages → Source: GitHub Actions).
